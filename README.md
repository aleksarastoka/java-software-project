# Java Software Project

University team project developed as part of the Software Design course at the School of Computing (RAF).

The project represents a complete Java application developed from the initial design and architecture to a functional implementation. Through this project, I gained practical experience with the full software development process, object-oriented programming, application architecture, separation of responsibilities, and the use of software design patterns.

## Technologies and Concepts

- Java
- Object-Oriented Programming
- Design Patterns
- Application Architecture
- Maven
- GUI Development
- Data persistence and serialization
- Git / Version Control

## Project Experience

The project involved designing and implementing a larger application composed of multiple interconnected components rather than isolated programming tasks.

Working on it gave me practical experience in:

- structuring a larger Java codebase
- designing relationships between classes and components
- implementing application logic
- applying software design patterns
- separating different responsibilities within the application
- working with Maven and external dependencies
- debugging and integrating different parts of a larger system
- developing software from the initial design phase to a complete working application
